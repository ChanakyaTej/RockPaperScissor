# 🎮 Rock Paper Scissors Game - Java Swing

A simple Rock Paper Scissors game built using **Java Swing** for the GUI and Java for the backend logic. Test your luck against the computer in this classic game!

---

## 🧩 Features

- 🪨 Rock, 📄 Paper, ✂️ Scissors buttons with responsive interaction
- 💻 Computer randomly generates its move each round
- 🧠 Score tracking for both player and computer
- 📦 Lightweight and easy to run
- 🖼️ User-friendly GUI made with Java Swing
- 📊 Pop-up dialog showing the result of each round

---

## 🛠️ How to Run

1. Make sure you have **Java installed**.
2. Open a terminal in the project directory.
3. Compile the files:

   ```bash
   javac *.java
